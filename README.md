# Sonic RE-RUN — BACK FROM THE CODE

**Sonic RE-RUN** is a **rebuild project based on the original version of Vs. Sonic.exe**, recreated from the ground up with the goal of preserving the identity and spirit of the original while expanding and modernizing the overall experience.

This project is not intended to be a simple port or copy. It rebuilds the game's systems, menus, settings, Freeplay, visual effects, gameplay elements, and overall presentation using **Codename Engine 1.0.1**.

## Features

* Full rebuild based on the original **Vs. Sonic.exe**
* Custom **Title Screen**
* Custom **Main Menu**

  * Story Mode
  * Freeplay
  * Options
  * Credits
* Custom **Settings System**
* Custom **Freeplay System**
* Custom save system for mod-specific settings
* Various visual effects:

  * RGB Glitch
  * Static
  * Screen Shake
  * Distortion
  * Visual Corruption
  * Fake Crash Effects
* Reworked gameplay and chart systems
* Custom stages and scripted events
* Performance and graphics options
* Built specifically for **Codename Engine 1.0.1**

## The Concept

> **BACK FROM THE CODE**

Sonic RE-RUN is built around the idea of returning to the original game's code and rebuilding the experience from its foundations.

The project aims to make the game feel familiar to fans of the original while introducing new systems, presentation, effects, and content that make **RE-RUN** its own experience.

**Sonic RE-RUN is a fan-made rebuild project based on the original Vs. Sonic.exe, created to revisit, rebuild, and expand the experience from the ground up.**
